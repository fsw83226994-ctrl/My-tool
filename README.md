# Soldier Pile Field Book

A daily-report tool for one construction job. This page holds the tool and public manual extracts only; it holds no job
data. The project file is loaded once on each device and stays on that device.

- `index.html` is the tool. Open the link in Safari, then Share and Add to Home Screen. Load the project file from the
  Home Screen copy (a Safari tab and the Home Screen copy keep separate records).
- `manuals/` holds split PDFs of public manuals (Standard Specifications, Construction Manual, Bridge Construction
  Memos, Trenching and Shoring Manual and others), one PDF per cited section, linked from the tool.
- `robots.txt` asks search engines to index nothing.

Records are kept in the browser on the device. Make a backup from the tool regularly.
